This isn't code written by the Āhau team — it's a third-party toolkit called Atala PRISM, built by an outside company for issuing and verifying digital identity credentials (think a verifiable digital ID card, rather than a physical one). It was pulled into this repository as a reference while the team explored whether it could support the paused digital-credentials work.

Since that work is on hold, this code isn't doing anything in the live system — it's kept around purely in case that idea gets picked back up later.
