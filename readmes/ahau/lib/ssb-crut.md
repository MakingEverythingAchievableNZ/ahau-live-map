This is one of the most foundational pieces in the whole system — nearly everything else is built on top of it. It provides the standard way records get created, read, updated, and retired. There's no true delete here, since the underlying network keeps a permanent log — instead, a record can be marked as no longer active, a process nicknamed "tombstoning."

Every change to a record is stored as its own entry in a chain, so the full history of edits is always kept. This is what makes it possible for two people to edit the same record while offline and have both sets of changes reconciled once they're back in contact. If their edits genuinely conflict — say, two different corrections to someone's name — the system keeps both versions on record until someone resolves it, rather than silently picking one and losing the other.
