This document explains how a family tree is actually built out of records behind the scenes: a profile for each person, a link between two profiles to say they're parent-and-child or partners, and a "view" that says where the tree should start and how it should be drawn.

It also covers a more sensitive case: family trees that a group's leaders (kaitiaki) want to keep fully private, visible only within their own leadership circle rather than the whole community. The document works through the tricky edge cases that come up when someone in that private space is linking to a person who already has a profile in the wider group — for example, whether to create a second, private-only profile for that person, or link to their existing one, and how to avoid accidentally creating duplicate profiles. Several of these edge cases were still open questions rather than settled decisions when this was written.
